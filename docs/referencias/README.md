# Referencias historicas

Esta carpeta reserva el lugar documental para insumos historicos usados durante la consolidacion editorial de TeoLingo v2.

Los archivos fuente mencionados en auditorias previas no estan versionados actualmente en esta rama. Si se recuperan desde respaldos, deben agregarse aqui solo cuando tengan valor de trazabilidad curricular o institucional.

Regla operativa:

- `public/` debe quedar para assets necesarios en runtime.
- `docs/` es la fuente de verdad documental.
- Bases locales como `local.db` se regeneran desde schema + seed y no se versionan.
