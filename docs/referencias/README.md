# Referencias y Archivos Históricos

Esta carpeta está destinada a almacenar documentos de análisis, planificación y archivos PDF originales (como el marco neurocognitivo IME original, PDFs de sustantivos, etc.) que sirvieron como base para el desarrollo de TeoLingo v2.

Actualmente, los archivos fueron retirados de la carpeta pública principal (`public/`) para limpiar el repositorio de producción, pero esta ubicación sirve como destino documentado para futuras auditorías o referencias pedagógicas del proyecto.
