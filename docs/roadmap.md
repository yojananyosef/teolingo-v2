# Roadmap operativo

Este roadmap prioriza estabilidad, calidad pedagogica y expansion curricular.

## Fase 0 (actual - completada)

- Migracion a Next.js App Router.
- Turso + Drizzle en produccion.
- Practica por frecuencia biblica.
- Modo sustantivos (`noun-parsing`).
- Flashcards SRS.
- Modo israeli (ILC).

## Fase 4 (6-12 meses) - consolidación institucional

1. Tablero docente (cohortes, avance, alertas).
2. Versionado curricular por periodo académico.
3. Export de reportes (progreso y evidencias).
4. Pipeline de contenido con control de calidad.

## KPI sugeridos por fase

- Retencion semanal (% usuarios activos en 7 dias).
- Finalizacion de sesiones (% sesiones completadas).
- Precision media por modalidad.
- Tiempo medio a dominio por set de contenidos.
- Reintentos necesarios por objetivo curricular.
