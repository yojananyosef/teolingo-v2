# Documentacion TeoLingo v2

Esta carpeta centraliza la documentacion funcional, tecnica y academica del proyecto.

## Indice

- `arquitectura-aplicacion.md`: arquitectura de software (frontend, backend, acciones y rutas).
- `arquitectura-base-datos.md`: modelo de datos, tablas y flujos principales.
- `defensa-proyecto.md`: documento de defensa institucional actualizado.
- `marco-neurocognitivo-ime.md`: integracion del marco teorico neurocognitivo e IME.
- `roadmap.md`: roadmap priorizado por fases con entregables.
- `plan-futuro.md`: plan estrategico 12-24 meses.
- `auditoria-y-limpieza.md`: auditoria funcional, tecnica y limpieza de artefactos.
- `referencias/`: insumos historicos y materiales fuente migrados desde `public/` y raiz.

## Convencion

- Esta carpeta es la fuente de verdad para documentacion.
- El `README.md` de la raiz queda como entrada rapida.
- Los documentos historicos obsoletos se migran aqui o se eliminan si no tienen uso.
